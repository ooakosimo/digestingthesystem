# DIGESTING THE SYSTEM

**An Interactive Archive by OOAKOSIMO**

DIGESTING THE SYSTEM is a browser-native interactive artwork about living inside systems: bureaucratic systems, technological systems, economic systems, interfaces, archives, memory, paperwork, absurdity, repetition, failure, digestion and survival.

It is not a static image.

It is a place to enter.

Click things. Open things. Trigger things. Wander around. Get processed.

---

## The work

DIGESTING THE SYSTEM treats the browser as both exhibition space and machine.

Fragments of interfaces, administrative language, documents, images, animations, interactions and small behavioral systems accumulate into an evolving digital archive.

The work borrows the visual language of offices, forms, terminals, institutional interfaces and personal digital debris, then turns them into something unstable, playful and occasionally ridiculous.

The system does not merely display its contents.

It digests them.

---

## Browser-native artwork

The project is built primarily from web technologies and is intended to run directly in a browser.

Current components include:

- HTML
- CSS
- JavaScript
- interactive browser behaviors
- image and interface assets
- self-contained / archival builds
- experimental sub-pages and systems

No installation is required for the public web version.

---

## XChain experiments

This repository is also being used as a preservation and metadata source while testing the work with XChain.

Experiments may include:

- XChain token metadata
- JSON metadata
- token icons
- externally hosted artwork
- XChain `FILE` actions
- on-chain media
- `data_ref: action:<index>`
- interactive HTML references
- contract-driven state
- cross-chain artwork behavior

The goal is not simply to tokenize a webpage.

The interesting question is whether an interactive artwork can retain identity, files, state and memory across changing platforms.
